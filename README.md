# 🎮 병무청 비주얼 노벨 대본: 「힘찬이와 함께하는 슬기로운 신검 라이프」

> **기획 목적**: 만 19세 병역의무자를 위해 실제 병역판정검사 절차(심리검사 $\rightarrow$ 임상병리 $\rightarrow$ 영상의학 $\rightarrow$ 신체계측 $\rightarrow$ 과목별 진료)를 사실적으로 시뮬레이션하고, **공공데이터포털(data.go.kr)과 국가법령정보센터(open.law.go.kr) Open API**를 결합하여 실시간 맞춤 정보와 함께 **e-병무지갑, 병역진로설계센터** 등 핵심 병무 행정 정책을 자연스럽게 홍보하는 인터랙티브 웹 서비스.
